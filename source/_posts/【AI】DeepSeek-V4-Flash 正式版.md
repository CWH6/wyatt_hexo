> 2026 年 7 月 31 日，DeepSeek 在官方 API 更新日志中低调宣布：DeepSeek-V4-Flash 正式版（版本号 V4-Flash-0731）上线公测。没有发布会、没有预告，却让全球开发者圈直接沸腾——一个激活参数仅 130 亿的轻量模型，在 Agent 能力上全面反超自家 Pro 旗舰，还把 OpenAI 的 Codex 生态给"策反"了。

## 一、事件速览：一场"悄无声息"的重磅发布

7 月 31 日下午，DeepSeek 在官方 API 文档的更新日志中宣布：**DeepSeek-V4-Flash 正式版 API 上线公测**（版本号 V4-Flash-0731）。

几个关键事实：

- **没有新架构**：模型结构、尺寸与 4 月 24 日发布的 V4-Flash 预览版**完全一致**，仅重新进行了后训练
- **无需改代码**：开发者继续用 `deepseek-v4-flash` 模型名调用，后台自动切换到新版本
- **仅限 API**：DeepSeek App、网页端以及 V4-Pro API 均未变化，普通用户打开 DeepSeek，体验和之前一模一样
- **V4-Pro 正式版仍在路上**：官方表示将"尽快发布"

也就是说，这是一次**只给开发者看的升级**，但信息量之大，让整个行业都坐不住了。

## 二、核心看点：Flash 把 Pro 给"以下克上"了

按照行业惯例，Pro 负责性能天花板，Flash 负责便宜大碗。但这次 DeepSeek 直接掀翻了这张桌子——**V4-Flash 正式版在 Agent 能力上，多项基准测试全面反超三个月前的 V4-Pro 预览版**。

### 2.1 官方公布的 9 项基准测试成绩

| ----------------------------------- | ---------------------- | --------------- | ------------- | --------------------------------------- |
| **Terminal Bench 2.1**        | **82.7**         | 61.8      | 72.1    | 终端操作测试（较预览版暴涨 20.9 分）     |

| **DeepSWE**                   | **54.4**         | 7.3       | 12.8    | 代码 Agent 任务（暴增近 7.5 倍）         |

一个惊人的事实：**9 项测试全部超越 V4-Pro 预览版，包括参数规模大得多的旗舰。** 其中差距最悬殊的是 Cybergym（76.7 vs 52.7，高 24 分）和 DeepSWE（54.4 vs 12.8，是 Pro 预览版的 4 倍以上）。

一个开源轻量版，在终端操作测试上**反超 GLM-5.2 和自家 V4-Pro 预览版**，距离闭源旗舰 Opus 4.8 只差 2.3 分；工具调用同样反超 Pro 预览版，差距也在快速收窄。**激活参数仅 130 亿的轻量模型跑出这个成绩，已经足以说明问题。**

**翻译成人话**：新版 Flash 不只更会写代码，也更擅长"自己动手干活"——拆解任务、调用工具、发现错误、从头到尾把一件事做完。

### 2.2 第三方独立评测也盖章了

官方自测可以打折听，但这次第三方评测跟官方数字对上了：

**Artificial Analysis（AA）**（独立第三方 AI 评测机构）在发布当天就把 Flash-0731 放上了榜单：**智能指数 50 分**，比 4 月发布的 Flash 预览版高 10 分，比自家 V4-Pro 还高 6 分，只比 OpenAI 最便宜款 GPT-5.6 Luna（51 分）低 1 分（GLM-5.2、Muse Spark 1.1 同为 51 分，开源榜第一的 Kimi K3 为 57 分）。而且它跑完整套测试用的 token 比上一版还少了 12%——效率和分数一起涨。

一个激活参数只有 130 亿的轻量模型，把参数规模大得多的自家旗舰预览版反超了。三个月前没人信这个。

与其他主流模型横向对比，差距更是直观——不仅反超 GLM-5.2，距离闭源旗舰 Claude Opus 4.8 也只剩一步之遥：

## 三、最离谱的一条：结构没动，只重做了后训练

Flash 正式版真正炸圈的不是分数，是官方日志角落里那句话：

> **"DeepSeek-V4-Flash-0731 的模型结构、尺寸和 DeepSeek-V4-Flash-preview 保持一致，仅重新进行了后训练。"**

284B 总参数、13B 激活参数，一个数都没改。4 月预览版发布时，官方还自己承认"高难度 Agent 任务和 Pro 有差距"；三个月后，同一个身子，把 Pro 反超了。

**打个比方**：基础训练像"上学"，后训练更像"入职后的专项练习"——模型原本就会写代码、读文档，现在要反复练习怎么拆解任务、选择工具、发现错误，把一件事从头做到尾。**身板没变，做事的习惯变了。**

这传递了一个极其深刻的信号：**在特定任务上，模型规模可能不再是决定性因素，训练方法和数据质量的权重正在快速上升。** 谁说后训练只是"锦上添花"？在 DeepSeek 手里，这是化腐朽为神奇。

## 四、技术底牌：百万上下文背后的工程细节

V4-Flash 的能力暴增不是凭空来的，它站在 V4 系列强大的架构基础上（《DeepSeek-V4: Towards Highly Efficient Million-Token Context Intelligence》技术报告）：

### 4.1 模型规格

| 参数         | V4-Pro                    | V4-Flash                 |
| ------------ | ------------------------- | ------------------------ |
| 总参数       | **1.6T（1.6万亿）** | **284B（2840亿）** |
| 激活参数     | **49B（490亿）**    | **13B（130亿）**   |
| 架构         | MoE 混合专家              | MoE 混合专家             |
| 上下文长度   | 1M tokens（原生）         | 1M tokens（原生）        |
| 最大输出长度 | 384K tokens               | 384K tokens              |
| 预训练数据   | 33T tokens                | 32T tokens               |
| 网络层数     | 未公布                    | 43 层                    |

**MoE（混合专家架构）**：把一个大模型拆成很多个"专家子模型"，每次推理只点亮其中一小部分参数，用更少的算力干活。284B 是仓库里全部的货，13B 是每次实际搬出来的。

### 4.2 原生支持 Responses API，适配 Codex

正式版 V4-Flash 在工程适配上也有重要更新——**原生支持 Responses API 格式，并针对性适配了 Codex**。这意味着开发者可以更自然地将 V4-Flash 接入现有的 Codex 工作流，降低迁移成本。具体配置方法可参考 DeepSeek 官方文档。

## 五、白菜价：2 元 vs 6 元 vs 12 美元

价格这块不用算太细也能看懂：Flash 的单价是自家 Pro 的三分之一，输出价只有 OpenAI 最便宜型号 Luna 的四分之一左右。

| 模型                               | 输出价格（每百万 token） |
| ---------------------------------- | ------------------------ |
| **DeepSeek V4-Flash 正式版** | **2 元人民币**     |
| DeepSeek V4-Pro                    | 6 元人民币               |
| Claude Opus 4.8                    | 25 美元（约 180 元）     |
| GPT-5.6 Luna（降价后）             | 1.2 美元（约 8.6 元）    |

V4-Flash 的输出成本仅为 Claude Opus 4.8 的约**九十分之一**；相比降价 80% 后的 GPT-5.6 Luna 仍便宜约 75%。

有开发者实测：一次 51 万 tokens 的本地文件阅读加全网信息检索汇总任务，总花费仅 **0.53 元**。用不到一瓶矿泉水的钱，完成了一次复杂的长文本跨平台信息整合任务。

## 六、行业观察：Agent 时代正式开启？

从 Terminal Bench 到 Cybergym，从 DeepSWE 到 Toolathlon，这 9 项基准测试的名字本身就揭示了一个趋势：**AI 的能力评测，正在从"写一段代码"进化到"完成一个工程任务"。**

DeepSeek-V4-Flash 正式版在多项 Agent 基准上远超 V4-Pro-Preview，释放了一个明确信号——**后训练时代的竞争焦点，已经从模型规模转向了 Agent 能力的深度优化。**

当 AI 能够熟练地操作终端、分析代码仓库、进行网络安全对抗、完成全栈开发任务时，我们或许正在见证一个新时代的开启：**AI 不再只是代码助手，而是成为了真正的 AI 工程师。**

正如业内人士分析的："当后训练的红利被充分挖掘，当效率的提升开始抵消参数的差距，大模型的竞争逻辑，可能要被重新书写了。"
